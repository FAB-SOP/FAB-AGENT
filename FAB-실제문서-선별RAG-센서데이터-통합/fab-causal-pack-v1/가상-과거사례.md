# 가상 과거 사례 7건

전부 팀이 만든 시연용 이야기입니다. 실제 기업·장비의 사건, 검증된 조치 절차가 아닙니다. 원문 근거와 사례의 관측/조치/결과를 혼동하지 않습니다.

## DEMO-CASE-001 · 입고 두께 정상, CMP 헤드 압력 저하

- 상태: CONFIRMED_WITHIN_FICTIONAL_STORY
- 관측: Etch 후 15010 Å, CMP 후 10190 Å / 헤드 설정 3 psi 대비 실제 2.89 psi / 회전·유량·시간은 기존 조건과 유사
- 추가 확인: 압력 readback 교정 / 공급·헤드 상태
- 가상 조치: 가상 담당자가 압력 제어 계통 점검 후 승인된 복구 절차 수행
- 가상 결과: 가상 확인 run 5회에서 압력과 제거량이 기준 범위로 복귀
- 남은 한계: 현실의 장비 고장·복구 결과를 의미하지 않음

## DEMO-CASE-002 · 슬러리 공급량 저하와 제거량 감소

- 상태: CONFIRMED_WITHIN_FICTIONAL_STORY
- 관측: 입고 두께는 기존 범위 / 슬러리 유량이 150에서 110 mL/min 수준으로 낮아짐 / 압력·회전·시간은 유사
- 추가 확인: 슬러리 배치·농도·사용 기한 / 유량계 교정 / 필터·배관·노즐
- 가상 조치: 가상 점검 기록에서 필터 오염 확인; 승인된 정비 후 확인 run
- 가상 결과: 가상 유량·제거량 회복
- 남은 한계: 유량 신호만으로 필터 오염이나 국소 분포 문제를 확정할 수 없음

## DEMO-CASE-003 · Etch 잔막 상승이 CMP까지 이어짐

- 상태: PROCESS_LOCALIZED_COMPONENT_UNCONFIRMED
- 관측: Etch 후 잔막 15125 Å, Etch UCL 15135 Å / CMP 제거량 약 4980 Å, 최종 10145 Å / Etch 주요 태그는 큰 편차 없음 / 가상 세정 이력 이후 식각 제거량 변화
- 추가 확인: 챔버 표면·시즈닝 / MFC/RF 교정 / 계측 재현성
- 가상 조치: Etch 담당자에게 해당 wafer 경로·제거량·세정 이력 확인 요청
- 가상 결과: 가상 모니터 run에서 Etch 제거량 변화 재현; 정확한 부품 원인은 미확인
- 남은 한계: 챔버 벽 또는 RF 고장으로 확정하지 않음

## DEMO-CASE-004 · CVD 소폭 두께 이동, 아직 OOC 아님

- 상태: MONITORING_NOT_A_CONFIRMED_FAULT
- 관측: CVD 후 약 20045 Å, UCL 20067 Å / 가스·온도 신호가 정상 분포 내에서 소폭 이동 / Etch/CMP 결과는 모두 관리 범위 내
- 추가 확인: 후속 run 추세 / 가스 readback·계측기·재료 변경
- 가상 조치: 추가 추세 확인; 현재 데이터만으로 고장·조치를 확정하지 않음
- 가상 결과: 가상 후속 자료 부족으로 관찰 유지
- 남은 한계: 소폭 이동은 정상 변동일 수 있음

## DEMO-CASE-005 · 태그는 정상, 패드 상태 확인 필요

- 상태: OPEN_UNCONFIRMED
- 관측: 압력·회전·유량·처리 시간 유사 / 패드 누적 사용 이력 증가 / 모터 전류 변화가 있지만 원인을 특정하지 못함
- 추가 확인: 슬러리 화학 상태 / 패드 표면·컨디셔닝 기록 / 계측 오류
- 가상 조치: 가상 패드/컨디셔닝 점검과 모니터 웨이퍼 확인 요청
- 가상 결과: 부품 원인 미확정; 담당자 확인 대기
- 남은 한계: 전류만으로 패드 마모·슬러리 상태를 구별할 수 없음

## DEMO-CASE-006 · 공정 이상처럼 보였던 계측 문제

- 상태: CONFIRMED_WITHIN_FICTIONAL_STORY
- 관측: 초기 계측 10180 Å / 독립 재측정 10010 Å / 가상 계측 레시피 버전 불일치 확인
- 추가 확인: 기준 시편 / 측정 위치와 광학 모델 / 진짜 공정 변동
- 가상 조치: 가상 계측 담당자가 측정 조건을 확인하고 승인 후 재측정
- 가상 결과: 가상 품질 기록 정정; 공정 레시피는 원인 확인 없이 변경하지 않음
- 남은 한계: 독립 재측정이 없으면 단순 센서값만으로 계측 문제를 확정 못 함

## DEMO-CASE-007 · 공정 시간 부족으로 덜 연마됨

- 상태: CONFIRMED_WITHIN_FICTIONAL_STORY
- 관측: 압력·유량·회전은 실행 구간에서 정상 / PROCESS 수행 시간이 레시피보다 짧음 / 중단 이벤트 존재
- 추가 확인: 중단 사유 / 레시피·종료 로직 / 실제 장비 알람
- 가상 조치: 가상 실행 로그 확인과 담당자 검토; 대상 웨이퍼 처리 방안 승인 요청
- 가상 결과: 가상 종료 이벤트 원인 확인 후 확인 run 수행
- 남은 한계: 남은 두께만 보고 동일 시간을 추가 연마하라고 지시하지 않음
