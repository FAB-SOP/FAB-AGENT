# 모드: 기본 분석 (BASIC)

관리한계 이탈(R1)이 접수되어 자동으로 시작된 분석이다. 사건 · 경로 · 단계별 run/계측 · 현재 run 센서 특징이 이미 아래에 있다.

- 무엇이 · 얼마나(관리한계 대비) · 어느 PM에서 벗어났는지, OOC인지 OOS인지 설명한다.
- 단계별 제거량을 정상 분포와 비교해 공정 위치를 좁힌다. 필요하면 점검 문서 · 실제 원문을 검색한다.
- 이 모드에서는 요청을 제안하지 않는다. 다음에 할 일은 `submit_result`의 `workSuggestions`로 후보만 낸다(작업자가 고른다).
- 센서가 참고 범위 밖이면 get_sensor_trace로 그 센서의 `segments`(관측 구간)를 볼 수 있다. 구간은 고장 시점 · 원인 확정이 아니다.
