# 공정 이상 조사 우선순위 판정 기준

## 1. 목적 및 적용 범위

본 문서는 공정 이상 사건의 조사 우선순위를 상·중·하로 구분하기 위한 팀 시연용 기준이다. CVD–Etch–CMP 합성 데이터에 적용하는 정책 초안이며, 실제 제조 현장의 승인된 관리 기준이나 설비 운전·안전 절차가 아니다. 검토·승인 후 활성화한 버전만 판정에 사용한다.

우선순위는 현재 확보된 관측 근거를 바탕으로 한 **조사 시급성**이다. 원인 확신도, 장비 고장 확정, 작업 승인, 설비 Parameter 조정 필요 여부를 뜻하지 않는다. 안전 알람·인터록은 별도의 승인된 대응 절차를 따른다.

## 2. 판정에 사용하는 근거

다음 정보를 같은 사건·분석 시점에 맞추어 확인한다.

- 대상 wafer와 공정 run, 공정·장비/챔버·레시피·제품/층.
- 핵심 계측값, 측정 품질과 공개 시각, 등록된 관리한계·제품 규격.
- 센서별 원시 시계열, 취득 품질, 공정 단계, 등록된 센서 기준 범위.
- 편차의 지속시간·회복 여부, 관련 센서 간 동반 발생, 비교 가능한 이전 run의 재발 여부.

수치와 구간은 조회·계산된 근거를 사용한다. AI 기본 분석의 설명문이나 과거 사례에 적힌 예시 숫자로 현재 측정값·관리한계·센서 허용값을 대신하지 않는다. 분석 시점 이후 공개된 계측·후속 결과를 소급하여 사용하지 않는다.

동일 공정·장비/챔버·레시피 및 비교 가능한 조건의 정상 이력과 비교한다. 앞 공정 기여는 같은 wafer의 실제 경로로 조사하며, 서로 다른 공정의 PM 번호가 같다는 이유로 경로를 연결하지 않는다.

## 3. 우선순위 결정표

아래 표를 위에서부터 적용한다. 상 조건이 충족되면 센서 이상 개수와 무관하게 상이다. 중 조건 중 하나라도 충족되면 하보다 우선한다.

화면의 우선순위 열과 배지는 **‘상’, ‘중’, ‘하’ 세 값만 표시**한다. ‘잠정 중’, ‘판정 대기’, ‘미분류’ 등의 별도 등급은 표시하지 않는다. 판정의 잠정 여부와 근거 부족 사유는 내부 메타데이터 및 상세 설명으로만 관리한다.

| 규칙 ID | 우선순위 | 판정 조건 | 조사 방향 |
|---|---|---|---|
| P-HIGH-01 | 상 | 유효한 핵심 계측값이 등록된 관리한계 또는 제품 규격을 벗어남 | 품질 영향, 계측 신뢰성, 현재·앞 공정 기여 우선 조사 |
| P-MEDIUM-01 | 중 | 계측 이상이 확인되지 않은 상태에서 유효 센서 편차가 지속 조건 충족 | 센서·공급·제어 계통과 후속 계측 확인 |
| P-MEDIUM-02 | 중 | 계측 이상이 확인되지 않은 상태에서 유효 센서 편차가 반복 조건 충족 | 재발 원인과 영향 범위 확인 |
| P-MEDIUM-03 | 중 | 계측 이상이 확인되지 않은 상태에서 관련 센서 2종 이상이 동반 편차 조건 충족 | 신호 간 연관성과 장비·공정 상태 확인 |
| P-MEDIUM-04 | 중 | 이미 접수된 사건이나 필수 계측·기준·취득 품질·반복 이력이 부족해 상/하 판정을 확정하기 어려움 | 내부적으로 임시 분류임을 기록하고 부족한 근거를 우선 확인 |
| P-LOW-01 | 하 | 계측 정상, 단일 센서의 유효한 짧은 편차가 고립되어 발생하고 회복했으며 상·중 조건 없음 | 취득 신뢰성·회복·재발 여부 확인 |

실행 순서: 유효 계측 이상 확인 → 상. 그렇지 않고 필수 근거가 부족하면 중(내부 임시 분류). 근거가 충분하면 지속·반복·동반 중 조건을 확인하고, 모두 아니면서 단일 짧은 편차가 회복했으면 하. 완전 정상인 신규 데이터는 사건을 만들지 않는다.

계측 미도착은 계측 정상과 다르다. 유효한 상 근거가 없고 필수 계측이 미도착이면 중으로 표시하고, 상세 사유에 계측 대기를 기록한다. 정보 부족 시 중으로 두는 것은 세 등급만 노출하기 위한 시연용 업무 배정 정책이며, 실제 이상 정도가 중으로 확인되었다는 뜻은 아니다. 단순 정보 누락만으로 신규 이상 사건을 생성하지 않는다.

## 4. 계측 이상 판정

### 4.1 관리한계 이탈과 규격 이탈

- OOC: 유효한 계측값에 등록된 관리 규칙을 적용한 결과 관리상태 이탈로 판정됨.
- OOS: 유효한 계측값이 등록된 제품 규격 밖에 있음.
- 본 시연 정책은 OOC 또는 OOS가 확인되면 상으로 분류한다.
- OOC와 OOS는 서로 다른 판정이며 동시에 발생할 수 있다. 각각의 상태를 보존한다.
- 규격 안이라도 OOC이면 상이 될 수 있다. 상이라는 이유만으로 제품 불량이나 장비 고장을 확정하지 않는다.

### 4.2 측정 품질 및 기준 부재

- 아직 원인을 모르는 유효한 계측 이상은 상의 조사 대상이다. 재측정 확인 전 ‘계측기 문제일 것’이라는 추정으로 하향하지 않는다.
- 이미 INVALID로 확인된 측정값은 유효한 정상 또는 유효한 OOC로 사용하지 않는다. 신뢰 가능한 재측정 등 추가 근거를 요구한다.
- 관리한계·규격·측정 항목의 적용 범위가 없거나 충돌하면 임의 기준을 만들지 않는다.

## 5. 센서 편차 판정

본 절의 시간·횟수는 합성 데이터 시연을 위한 제안값이다. 실제 장비 특성에 맞게 검증된 기준이 아니며, 활성화 전에 센서별 샘플 주기·단계·관련 센서 그룹을 확인해야 한다. 기존 서비스의 2초 이동평균·5초 지속 검출과는 다른 새 제안이다.

| 항목 | 본 정책의 시연용 정의 |
|---|---|
| 대상 구간 | 이번 시연은 run 시작 기준 [readySeconds+2, readySeconds+processSeconds). 시작 포함·끝 제외. 준비·종료 구간 제외 |
| 유효 데이터 | 취득 품질 GOOD 또는 GOOD_SYNTHETIC, 해당 시간 조건을 평가할 수 있는 샘플 주기 |
| 기준 범위 | 해당 센서·조건에 등록된 envelope 하한·상한. 다른 문서의 예시 숫자를 대신 사용하지 않음 |
| 평활 신호 | 현재 시각 t에서 [t−1초,t]의 양 끝 샘플을 포함한 산술평균. 창의 실제 시각 폭이 1초를 채운 후 판정. 계산 전 다운샘플링 금지 |
| 유효 편차 | 평활 신호가 같은 방향으로 기준 범위 밖에 1초 이상 연속 존재 |
| 짧은 편차 | 유효 편차 구간이 1초 이상 5초 미만이며 이후 기준 안으로 회복 |
| 지속 편차 | 유효 편차 구간이 5초 이상 지속 |
| 반복 편차 | 현재 run 포함, 현재 run 종료 시각까지 완료된 최근 비교 가능한 3개 run 중 같은 센서에서 2개 이상에 유효 편차 발생. 공정·장비·recipeId·제품·층이 일치하며 같은 안정 구간으로 계산. 미래/FOLLOWUP run 제외 |
| 동반 편차 | 같은 run에서 사전 등록된 관련 센서 2종 이상의 유효 편차 구간이 1초 이상 중첩. 이번 시연의 CMP_ROTATION_PAIR = platen_speed + head_speed |

핵심 계측은 각 공정의 `WAFER_5_SITE_MEAN`(Å)이며 등록 `quality-limits.json`의 공정별 기준을 사용한다. 이번 경로 기반 시연에서 하를 확정하려면 해당 wafer의 CVD·Etch·CMP 계측이 모두 공개되어 정상이어야 한다. 참조 envelope는 기존 합성 팩의 매칭된 PM 공통 기준을 재사용한다. 단, 그 파일의 `DEMO-SEGMENT-V2`는 기존 검출기 버전이지 본 정책의 새 검출 버전이 아니다.

이번 기준은 원시 샘플 간격이 1초 이하이고 1초 창을 평가할 수 있는 데이터에 적용한다. 샘플 한 점을 초 단위 지속시간으로 세지 않는다. 편차 시작·끝은 각각 기준 밖 평활값의 첫·마지막 샘플 시각이며 지속시간은 끝−시작이다. 방향이 바뀌면 이전 구간을 닫고 새 구간을 시작한다. 기준 안 평활값이 확인되어야 회복으로 인정하며, 데이터 끝이나 결측만으로 회복했다고 판단하지 않는다. 동반 중첩 시간은 min(끝 시각)−max(시작 시각)이며 1초 이상이어야 한다.

주의 사항:

- 지속시간은 평활 신호의 이탈 구간 기준이다. 원본 신호의 이탈 시작 시각과 판정 확정 시각을 구분한다.
- 같은 센서에서 여러 편차가 발생해도 센서 종류 수는 1종이다.
- 대상 사건에 등록된 전체 센서 목록의 길이를 이상 센서 수로 사용하지 않는다.
- 무관한 센서 또는 서로 다른 공정/run의 센서를 합쳐 동반 편차로 판정하지 않는다.
- 결측·불량 취득에서는 편차 구간과 평활 창을 끊는다. 결측을 가로질러 지속 편차를 연결하지 않는다.
- 반복 평가용 이력이 부족하면 반복 없음으로 단정하지 않는다. 유효한 상 근거가 없으면 중으로 표시하고 상세 사유에 ‘반복 여부 미확인’을 기록한다.
- 단일 샘플 튐 등 유효 편차 조건을 충족하지 못한 신호는 본 정책의 신규 이상 사건 생성 근거에서 제외한다. 별도의 데이터 품질 문제로 기록할 수 있다.
- run 전체 평균이 정상이어도 특정 시간 구간의 유효 편차는 별도로 평가한다.

## 6. 정보 부족과 정상 사건의 처리

| 근거 상태 | 처리 |
|---|---|
| 유효한 핵심 계측 이상 확인, 일부 센서 결측 | 상. 누락 센서는 추가 확인 사항으로 표시 |
| 계측만 미도착, 유효한 상 근거 없음 | 중. 상세 사유에 ‘계측 대기’, 내부적으로 잠정 판정 기록 |
| 단일 짧은 센서 편차 확인, 반복 평가 이력 부족 | 중. 상세 사유에 ‘반복 여부 미확인’ 기록 |
| 센서 편차 진행 중으로 회복·최종 지속시간 미확정 | 중. 회복 및 필수 근거 확보 후 재평가 |
| 필요한 기준 없음, 데이터 품질 불량 등으로 판정 근거 부족 | 이미 접수된 사건은 중. 상세 사유에 필요한 기준·근거 기록 |
| 필수 계측·센서 근거가 모두 정상이며 유효 편차 없음 | 신규 이상 사건을 생성하지 않음. 기존 사건을 재검토한 결과라면 하로 표시하고 정상 확인 근거를 기록하되 종료는 별도 처리 |

‘하’는 정보 부족을 채우는 기본값이 아니다. 기존에 유효한 상 조건을 확인했다면 무관한 결측 때문에 중으로 낮추지 않는다. 우선순위와 사건의 종료 상태는 구분한다.

## 7. 기본 분석과의 일관성 검토

우선순위는 기본 분석과 같은 실제 관측 근거를 공유한다. 기본 분석은 원인 후보와 추가 확인 사항을 설명하고, 우선순위는 본 문서의 조건에 따라 조사 순서를 제시한다.

- 기본 분석이 장비 고장을 확신한다고 해도 유효한 관측 근거 없이 상으로 올리지 않는다.
- 유효한 계측 OOC가 있는데 설명문이 정상이라고 하면 상을 유지하고, 설명과 관측 판정의 불일치를 재검토한다.
- 질문 문구나 AI 답변 표현만 바뀐 경우 등급을 임의 변경하지 않는다.
- 본 문서는 실측값을 대체하지 않는다. 기준 문서와 실제 계산 근거를 함께 제시해야 한다.

## 8. 판정 이유 및 재평가

판정에는 등급뿐 아니라 다음을 함께 남긴다.

- 적용 규칙 ID와 정책 문서 ID·버전.
- 대상 run과 실제 계측·센서 근거의 식별자.
- 판정 이유와 부족한 근거.
- 확정 가능한 현재 판정인지 잠정 판정인지의 상태.
- 판정 시각과 근거 조회 기준 시각.

우선순위 열은 아래의 등급만 표시한다. 오른쪽 설명은 별도의 상세 사유이며 배지에 붙이지 않는다.

| 우선순위 표시 | 상세 사유 예 |
|---|---|
| 상 | 최종 두께가 등록 관리상한 초과 |
| 중 | 헤드 압력의 유효 편차가 5초 이상 지속 |
| 하 | 단일 센서의 짧은 편차 후 회복, 계측 정상 |
| 중 | 계측 대기. 결과 도착 후 재평가 예정 |
| 중 | 적용 가능한 센서 기준을 확인해야 함 |

새 계측 도착, 재발 확인, 유효한 측정 정정, 승인된 기준 변경 시 재평가한다. 변경 전후 등급·근거·시각·이유를 보존한다. 회신 완료·보고서 확정·AI 답변 변경만으로 등급을 자동 하향하거나 사건을 종료하지 않는다.

## 9. 적용 한계

본 문서는 조사 우선순위만 정의한다. 어떤 등급도 자동 Parameter 변경, 작업 승인, 고장 확정 또는 사건 종료의 근거가 되지 않는다. 센서 편차는 실제 공정 변화, 공급·제어 계통 문제, 센서 교정·취득 문제 등 여러 가능성을 포함한다. 필요한 점검과 변경 작업은 별도의 담당자 검토·권한·승인 절차에 따른다.

## 10. 적용 패키지와 판정 시점

별도 제안 패키지 `l011-l012-priority-addon-20261022`의 `policy/priority-rules.json`에 본 버전의 구조화 파라미터가 있다. 문서와 설정은 모두 DRAFT이며 자동 활성화하지 않는다. 검출기 식별자는 `DEMO-PRIORITY-SEGMENT-V1`이다. RAG는 본 문서를 검색하고, 계산 도구가 동일 버전의 설정과 실제 원시 근거로 판정한다. 기존 2초/5초 검출기만으로 새 사례가 검출된다고 가정하지 않는다.

제안 데이터의 최종 등급은 기존 팩과 같은 `2026-10-20T11:59:00+09:00` 시점의 공개 근거로 평가한다. 이 시점에는 두 LOT의 계측과 반복 비교 이력이 확보되어 있다. 최초 센서 이벤트 접수 시점에는 계측이 미도착할 수 있으므로 중으로 임시 표시하고, 계측 도착과 편차 회복 확인 후 재평가한다. 따라서 L011은 초기 중에서 최종 하로 바뀔 수 있으며 모순이 아니다. 원인 확정·정비 완료·후속 개선은 이 데이터로 입증하지 않는다.

실측 입력에 기대 등급을 넣어 답을 유도하지 않는다. `evaluation/`의 기대 결과는 검증자 전용으로, Agent·지식 MCP·RAG 색인에는 노출하지 않는다.
