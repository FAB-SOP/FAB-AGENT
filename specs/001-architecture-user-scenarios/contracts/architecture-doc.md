## 표기 규칙

- 다이어그램은 Mermaid. 블록마다 `mmdc`로 렌더링 오류가 없어야 한다.
- 실선 = 현재 구현. 예정 항목은 `classDef planned`(점선 테두리) + 라벨 「예정 ·」 접두어 + 1.6 표에 행 하나.
- 코드 이름(노드 · 도구 · 패키지 · 환경 변수)은 코드와 글자까지 같아야 한다.
- 수치(API 수 · 도구 수 · 상한 · 포트)는 research.md R3의 출처 우선순위로 확인한다.
- 비밀값(실제 키)은 쓰지 않는다. 개발용 고정 토큰 이름은 써도 되지만 운영값이 아님을 밝힌다.
